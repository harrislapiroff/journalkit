# Tutorial

A guided path from nothing to a printed journal with a module of your own.
Each step builds on the one before and takes a few minutes. You will need a
terminal and a text editor.

1. [Install](install.md) — journalkit, Inkscape, Ghostscript and a font.
2. [Your first journal](first-journal.md) — scaffold a project, build it,
   look at the result.
3. [Add a page](add-a-page.md) — write a new template from scratch and learn
   what the grid does for you.
4. [Write a module](write-a-module.md) — add a module type in a dozen lines of
   Python and use it from YAML.

When you are done, the [Guides](../guide/index.md) cover specific tasks and
the [Reference](../reference/index.md) has every option.
